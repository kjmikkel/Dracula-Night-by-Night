# App Plan A: Real-time Reading — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A reader chooses how to read on a Welcome screen, controls it from Settings (mode, start date, skip ahead, notifications, text size, reading font, theme, high contrast, Start over), and is quietly notified when entries arrive.

**Architecture:** All behaviour is pure Kotlin tested on the JVM: saved state (`user/`), schedule rules (`domain/`: readable, arrivals, skip ahead, wake time, start over, season prompt, start tomorrow), what to notify (`notify/NotificationPlan.kt`), what each screen shows (`welcome/Welcome.kt`, `timeline/Timeline.kt`, `settings/Settings.kt`) and the palettes with their contrast (`ui/Palette.kt`). Android glue — Compose screens, view models, the alarm and receivers — is thin and verified on the emulator. The app has one clock (`ShiftableClock`), which debug builds can move (time travel), so timed behaviour is checked on a device in minutes. Notifications use one inexact countdown alarm allowed in Doze (`AlarmManager.setAndAllowWhileIdle`), approached halfway so Android's delivery window stays short.

**Tech Stack:** as App plan 1 (AGP 9.4.1, Kotlin 2.4.21, Compose BOM 2026.09.00, Navigation 2.10.2, Lifecycle 2.11.0, DataStore 1.2.1, kotlinx-serialization 1.11.0) plus `androidx.core:core-ktx` 1.19.1. Fonts: Atkinson Hyperlegible and OpenDyslexic (SIL Open Font License 1.1).

**Spec:** `docs/superpowers/specs/2026-10-15-app-plan-a-design.md` (decisions D1–D12), revising `docs/superpowers/specs/2026-10-14-app-design.md`.

**Prerequisite:** App plan 1 is merged, including PR #38 (App 6 and the final review's fixes). This plan was written against that code and verified task by task in a scratch copy: every code block below compiled, every test count below was observed (and re-observed by replaying the plan into a fresh checkout), and the emulator checks were run.

## Global Constraints

- Package `com.jensen.draculanightbynight`; minSdk 26; compileSdk and targetSdk 37.
- Fully offline: no `INTERNET` permission, no analytics, no accounts. New permissions: `POST_NOTIFICATIONS` (asked in context) and `RECEIVE_BOOT_COMPLETED`. Never the exact-alarm permissions.
- Notifications are silent by default (channel "New entries", importance Low); no in-app quiet hours (D1).
- Once read, always readable (D3); the Next card, arrivals and notifications use the schedule alone.
- Every schedule change moves the notification baseline (`lastNotifiedAt`) to now: entries that arrive because of something the reader did are never announced.
- Saved state: every new field has a default; an unknown choice (`"textSize": "huge"`) falls back to the default; plan 1 files load unchanged and count as onboarded.
- The app's text is English, so every date is formatted with `Locale.ENGLISH` (`content/Dates.kt`), whatever the phone's language.
- Contrast: every text/background pair ≥ 4.5:1 in the standard palettes and ≥ 7:1 in the high-contrast ones (`PaletteTest`).
- Fonts are bundled with their OFL licence texts in `assets/licenses/`; they are never modified (OpenDyslexic is a Reserved Font Name).
- Gradle needs the Android Studio JBR: run every Gradle command from `app/` as `JAVA_HOME="C:/Program Files/Android/Android Studio/jbr" ./gradlew …`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; PR bodies end with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.

## Rulings made while writing this plan (flagged for the maintainer)

1. **Alarms are approached halfway and count down** (`alarmFor`, `ELAPSED_REALTIME_WAKEUP`). Measured on the emulator: an alarm aimed straight at an entry 7 minutes ahead got a 5-minute window and fired at its very end (5 minutes late); one 8 hours ahead got a 1-hour window. Android gives inexact alarms a window of up to 75 % of their lead time, capped at an hour. Aiming halfway, waking and aiming again (measured: 21:32 → 21:49 → 21:55 → 22:00, windows 20, 8, 3 and 1.2 minutes) delivered the 22:00 entry by 22:01:32, for about ten sub-second wakes a day. The spec's "usually within a minute or two" holds only with this. The alarm counts down from the app's clock rather than naming a wall-clock time, so it stays right under time travel; device clock changes reset it anyway.
2. **Dates are always English** (`content/Dates.kt`). Plan 1 formatted with the phone's locale, so a Danish phone showed "torsdag 15 oktober" in an English app. Found because the notification test failed on this machine's Danish locale.
3. **The Next card shows when the entry really arrives**, its schedule moved earlier by skip ahead; plan 1 showed the unshifted schedule, which is wrong once the reader is ahead.
4. **"Read it now" confirms when the reader is in real time** and not when already ahead, instead of storing a "seen once" flag.
5. **A reader without a notification baseline gets one on the first reschedule** (plan 1 installs, or the very first run), so the first alarm never announces the whole backlog and later ones work.
6. **`ensureMode` stays** as a repair: an onboarded reader whose saved mode cannot be read restarts Same tempo from today instead of seeing a timeline that never loads.
7. **The dark palette's oxblood is lightened** from `#D06A6A` to `#DB8280`: the old one was 4.40:1 on the dark surface variant, under WCAG AA.
8. **Start tomorrow in Settings is its own row** under Start date (shown only when the tempo started today and the first entry is close) rather than a hint inside the date picker.
9. **Start over from a timeline card also answers the season prompt**, so the card does not come back the same year.
10. **`typeLabel` moves to `content/DocumentLabels.kt`** because notifications need it as well as the screens.
11. **Nine tasks instead of the spec's six:** debug time travel (asked for by the maintainer while the plan was written) comes before the screens so every emulator check can use it; Display and Notifications stand alone; the timeline cards are split from Settings.
12. **Time travel is debug-only and shell-only:** the receiver lives in `src/debug/` and requires `android.permission.DUMP`, which the adb shell holds and ordinary apps cannot.
13. **The season card and the "ahead" banner are pinned above the timeline list.** Found on the emulator: the list opens scrolled to the first unread entry, which hid both cards.
14. **Switch rows toggle as a whole** (Welcome's "Notify me", Settings' "Notify me" and "High contrast"): one target for touch and TalkBack. Found on the emulator: tapping the label did nothing.

```kotlin
import java.time.Instant
```

```kotlin
/**
 * Once read, always readable: an entry the reader has opened stays available even when the schedule no longer
 * unlocks it (back to real time, a mode switch, a zone moved west, a clock set back). Unread entries follow the
 * schedule. The Next card, arrivals and notifications use the schedule alone.
 */
fun isReadable(entry: Entry, settings: ReadingSettings, user: UserState, now: Instant, zone: ZoneId): Boolean =
    user.progressOf(entry.id).readAtMillis != null || UnlockSchedule.isUnlocked(entry, settings, now, zone)
```

```kotlin
package com.jensen.draculanightbynight.reader

import com.jensen.draculanightbynight.content.DocumentType
import com.jensen.draculanightbynight.content.Entry
import com.jensen.draculanightbynight.content.Story
import com.jensen.draculanightbynight.domain.ReadingSettings
import com.jensen.draculanightbynight.domain.isReadable
import com.jensen.draculanightbynight.user.UserState
import java.time.Instant
import java.time.ZoneId

/** How an entry's heading is framed; the body always uses the same reading font. */
enum class HeaderStyle { DIARY, LETTER, TELEGRAM, NEWSPAPER, MEMO, LOG }

fun headerStyle(type: DocumentType): HeaderStyle = when (type) {
    DocumentType.DIARY, DocumentType.PHONOGRAPH -> HeaderStyle.DIARY
    DocumentType.LETTER -> HeaderStyle.LETTER
    DocumentType.TELEGRAM -> HeaderStyle.TELEGRAM
    DocumentType.NEWSPAPER -> HeaderStyle.NEWSPAPER
    DocumentType.MEMO -> HeaderStyle.MEMO
    DocumentType.LOG -> HeaderStyle.LOG
}

data class ReaderState(
    val entry: Entry,
    val authorName: String,
    val recipientName: String?,
    val style: HeaderStyle,
    val previousId: String?,
    val nextId: String?,
    val startBlock: Int,
    val startOffset: Int,
    val bookmarked: Boolean,
)

/** The reader for entry [id], or null if it does not exist or is not readable (locked and never read). */
fun buildReader(story: Story, user: UserState, settings: ReadingSettings, now: Instant, zone: ZoneId, id: String): ReaderState? {
    val unlocked = story.entries.filter { isReadable(it, settings, user, now, zone) }
    val index = unlocked.indexOfFirst { it.id == id }
    if (index < 0) return null
    val entry = unlocked[index]
    val progress = user.progressOf(id)
    return ReaderState(
        entry = entry,
        authorName = story.nameOf(entry.author) ?: entry.author,
        recipientName = story.nameOf(entry.recipient),
        style = headerStyle(entry.type),
        previousId = unlocked.getOrNull(index - 1)?.id,
        nextId = unlocked.getOrNull(index + 1)?.id,
        startBlock = progress.blockIndex.coerceIn(0, (entry.body.size - 1).coerceAtLeast(0)),
        startOffset = progress.blockOffset,
        bookmarked = progress.bookmarked,
    )
}

// The reader's list shows the header as item 0 and body block i as item i + 1.

/**
 * The (block, offset) to store for a list scrolled to [firstVisibleItem] at [offset] pixels.
 * Anywhere in the header is the top of the entry: (0, 0), which [listPosition] opens at the header.
 */
fun savedPosition(firstVisibleItem: Int, offset: Int): Pair<Int, Int> =
    if (firstVisibleItem == 0) 0 to 0 else (firstVisibleItem - 1) to offset

/** The list item and offset to open at for a stored (block, offset). */
fun listPosition(block: Int, offset: Int): Pair<Int, Int> = (block + if (block > 0 || offset > 0) 1 else 0) to offset
```

```kotlin
private val HOUR_MINUTE = DateTimeFormatter.ofPattern("HH:mm")

/** What the timeline shows at [now]: readable entries grouped by in-story day, plus the next one to unlock. */
fun buildTimeline(story: Story, user: UserState, settings: ReadingSettings, now: Instant, zone: ZoneId): TimelineState {
    val (unlocked, locked) = story.entries.partition { isReadable(it, settings, user, now, zone) }
    val rows = unlocked.map { e ->
        val progress = user.progressOf(e.id)
        e.date to TimelineRow(
            id = e.id,
            authorName = story.nameOf(e.author) ?: e.author,
            type = e.type,
            timeLabel = e.time.format(HOUR_MINUTE),
            timeEstimated = e.timeEstimated,
            place = e.place,
            preview = e.preview,
            unread = progress.readAtMillis == null,
            bookmarked = progress.bookmarked,
        )
    }
    val days = rows.groupBy({ it.first }, { it.second }).map { (date, dayRows) -> TimelineDay(date, dayRows) }
    val next = locked
        .mapNotNull { e -> UnlockSchedule.unlockInstant(e, settings.mode, zone)?.let { e to it } }
        .minByOrNull { it.second }
        ?.let { (e, at) -> NextTeaser(story.nameOf(e.author) ?: e.author, e.type, at.atZone(zone)) }
    return TimelineState(
        days = days,
        next = next,
        firstUnreadId = rows.firstOrNull { it.second.unread }?.second?.id,
        unlockedCount = unlocked.size,
        total = story.entries.size,
    )
}
```

```kotlin
import com.jensen.draculanightbynight.user.UserState
import java.time.Instant
import java.time.LocalDate
import java.time.LocalTime
import java.time.MonthDay
import java.time.ZoneId

/** "Dracula begins again on 3 May": offered to Calendar readers a week before a new season, once a year. */
object SeasonPrompt {
    private val OPENS: MonthDay = MonthDay.of(4, 26)
    private val NOTIFY_TIME: LocalTime = LocalTime.of(10, 0)

    /** True from 26 April of a year after the reader's season until they answer (Start over or Not now). */
    fun isDue(user: UserState, today: LocalDate): Boolean {
        val mode = user.readingMode as? ReadingMode.Calendar ?: return false
        return today.year > mode.seasonYear && !MonthDay.from(today).isBefore(OPENS) && user.seasonPromptYear != today.year
    }

    /** When the prompt's notification is due: 26 April, 10:00, of the first year it has not been answered in. */
    fun notifyAt(user: UserState, zone: ZoneId): Instant? {
        val mode = user.readingMode as? ReadingMode.Calendar ?: return null
        val year = maxOf(mode.seasonYear + 1, (user.seasonPromptYear ?: 0) + 1)
        return OPENS.atYear(year).atTime(NOTIFY_TIME).atZone(zone).toInstant()
    }
}
```

```kotlin
package com.jensen.draculanightbynight.domain

import com.jensen.draculanightbynight.user.EntryProgress
import com.jensen.draculanightbynight.user.UserState
import java.time.LocalDate

/**
 * The reader's state after Start over: reading progress cleared (bookmarks kept unless [removeBookmarks]),
 * skip ahead reset, Calendar moved to the season that [today] belongs to, Same tempo restarted from
 * [tempoStart]. Mode kind and display settings are kept. [nowMillis] becomes the notification baseline, so
 * restarting never produces a burst of notifications.
 */
fun UserState.startedOver(removeBookmarks: Boolean, today: LocalDate, tempoStart: LocalDate, nowMillis: Long): UserState {
    val kept = if (removeBookmarks) emptyMap() else progress.filterValues { it.bookmarked }.mapValues { EntryProgress(bookmarked = true) }
    val restarted = when (readingMode) {
        is ReadingMode.Calendar -> withMode(ReadingMode.Calendar(UnlockSchedule.seasonYearFor(today)))
        is ReadingMode.SameTempo -> withMode(ReadingMode.SameTempo(tempoStart))
        ReadingMode.Free, null -> this
    }
    return restarted.copy(progress = kept, skipAheadMinutes = 0, lastNotifiedAt = nowMillis)
}
```

```kotlin
import com.jensen.draculanightbynight.domain.ReadingMode
import com.jensen.draculanightbynight.domain.TimeSource
import com.jensen.draculanightbynight.domain.startedOver
import kotlinx.coroutines.flow.Flow
import java.time.LocalDate

class UserRepository(private val store: DataStore<UserState>, private val time: TimeSource) {
    val state: Flow<UserState> = store.data

    /** First launch: until onboarding exists, a new reader starts in Same tempo from today. */
    suspend fun ensureMode() {
        store.updateData { s -> if (s.readingMode == null) s.withMode(ReadingMode.SameTempo(time.today())) else s }
    }

    suspend fun setMode(mode: ReadingMode) {
        store.updateData { it.withMode(mode) }
    }

    /** Records the first time an entry was opened; reopening keeps the original time. */
    suspend fun markRead(id: String) {
        store.updateData { s -> s.updateProgress(id) { p -> if (p.readAtMillis != null) p else p.copy(readAtMillis = time.millis()) } }
    }

    suspend fun savePosition(id: String, blockIndex: Int, blockOffset: Int) {
        store.updateData { s -> s.updateProgress(id) { it.copy(blockIndex = blockIndex, blockOffset = blockOffset) } }
    }

    suspend fun toggleBookmark(id: String) {
        store.updateData { s -> s.updateProgress(id) { it.copy(bookmarked = !it.bookmarked) } }
    }

    /** Start over: see [startedOver]. [tempoStart] is the Same tempo restart date (ignored in other modes). */
    suspend fun startOver(removeBookmarks: Boolean, tempoStart: LocalDate) {
        store.updateData { it.startedOver(removeBookmarks, time.today(), tempoStart, time.millis()) }
    }

    /** Records that this year's new-season prompt was answered (Start over or Not now). */
    suspend fun answerSeasonPrompt() {
        store.updateData { it.copy(seasonPromptYear = time.today().year) }
    }
}
```

```kotlin
import java.time.Instant
```

```kotlin
/** When entries arrive by the schedule alone: what notifications announce and what the Next card shows. */
object Arrivals {
    /** The real instant [entry] arrives: its scheduled unlock moved earlier by skip ahead; null in Read freely. */
    fun arrivesAt(entry: Entry, settings: ReadingSettings, zone: ZoneId): Instant? =
        UnlockSchedule.unlockInstant(entry, settings.mode, zone)?.minus(settings.skipAhead)

    /** Unread entries that arrive in (from, to], in story order. */

        story.entries.filter { entry ->
```

```kotlin
/** The skip-ahead offsets behind "Read it now" and "Skip to a day". Both only ever move the offset forwards. */
object SkipAhead {
    private const val MINUTE_MILLIS = 60_000L

    /** Minutes of skip ahead that make the next unread entry (and any arriving with it) readable at [now]. */
    fun toNext(story: Story, user: UserState, settings: ReadingSettings, now: Instant, zone: ZoneId): Long {
        val current = settings.skipAhead.toMinutes()
        val next = Arrivals.nextAfter(story, user, settings, now, zone) ?: return current
        return current + ceilMinutes(Duration.between(now, next))
    }

    /** Minutes of skip ahead that unlock every entry up to the end of story day [day]; never less than now. */
    fun toEndOf(day: LocalDate, story: Story, settings: ReadingSettings, now: Instant, zone: ZoneId): Long {
        val current = settings.skipAhead.toMinutes()
        val last = story.entries
            .filter { !it.date.isAfter(day) }
            .mapNotNull { UnlockSchedule.unlockInstant(it, settings.mode, zone) }
            .maxOrNull() ?: return current
        return maxOf(current, ceilMinutes(Duration.between(now, last)))
    }

    private fun ceilMinutes(duration: Duration): Long {
        val millis = duration.toMillis()
        return if (millis <= 0) 0 else (millis + MINUTE_MILLIS - 1) / MINUTE_MILLIS
    }
}
```

```kotlin
            intent.hasExtra("at") -> app.clock.travelTo(LocalDateTime.parse(intent.getStringExtra("at")).atZone(ZoneId.systemDefault()).toInstant())

        }
        app.onTimeChanged()
        Log.i("TimeTravel", "now ${app.time.now()} (offset ${app.clock.offset})")
```

```kotlin
package com.jensen.draculanightbynight.domain

import java.time.Clock
import java.time.Duration
import java.time.Instant
import java.time.ZoneId

/**
 * The app's clock: the device's [base] clock moved by [offset]. The offset stays zero except in debug builds,
 * where the time-travel receiver moves it so timed behaviour can be checked in seconds instead of hours.
 */
class ShiftableClock(private val base: Clock) : Clock() {
    @Volatile
    var offset: Duration = Duration.ZERO
        private set

    override fun getZone(): ZoneId = base.zone

    override fun withZone(zone: ZoneId): Clock = ShiftableClock(base.withZone(zone)).also { it.offset = offset }

    override fun instant(): Instant = base.instant().plus(offset)

    /** From now on the clock reads [target] and keeps running from there. */
    fun travelTo(target: Instant) {
        offset = Duration.between(base.instant(), target)
    }

    fun travelBy(duration: Duration) {
        offset = offset.plus(duration)
    }

    fun reset() {
        offset = Duration.ZERO
    }
}
```

```kotlin
/** A text colour and the background it is drawn on, as ARGB. */
data class TextPair(val name: String, val foreground: Long, val background: Long)

/**
 * The app's colours as plain ARGB values, so their contrast can be checked on the JVM. [Theme] turns a palette
 * into a Material colour scheme. Text is drawn in on*, primary and error colours on the backgrounds below.
 */
data class Palette(
    val name: String,
    val isDark: Boolean,
    val background: Long,
    val onBackground: Long,
    val surface: Long,
    val onSurface: Long,
    val surfaceVariant: Long,
    val onSurfaceVariant: Long,
    val containers: List<Long>, // lowest, low, normal, high, highest
    val primary: Long,
    val onPrimary: Long,
    val secondary: Long,
    val outline: Long,
    val error: Long,
) {
    /** Every text colour on every background it appears on. */
    fun textPairs(): List<TextPair> {
        val backgrounds = listOf("background" to background, "surface" to surface, "surfaceVariant" to surfaceVariant) +
            containers.mapIndexed { i, c -> "container$i" to c }
        val texts = listOf("onSurface" to onSurface, "onSurfaceVariant" to onSurfaceVariant, "primary" to primary, "error" to error)
        return texts.flatMap { (tn, t) -> backgrounds.map { (bn, b) -> TextPair("$tn on $bn", t, b) } } +
            TextPair("onBackground on background", onBackground, background) +
            TextPair("onPrimary on primary", onPrimary, primary)
    }
}

/**
 * The palette for the reader's choices. [highContrast] null means "follow Android" ([systemHighContrast],
 * Android 14+'s Contrast setting); once the reader sets the switch, their choice wins.
 */
fun paletteFor(theme: ThemeChoice, systemDark: Boolean, highContrast: Boolean?, systemHighContrast: Boolean): Palette {
    val dark = when (theme) {
        ThemeChoice.SYSTEM -> systemDark
        ThemeChoice.LIGHT -> false
        ThemeChoice.DARK -> true
    }
    val high = highContrast ?: systemHighContrast
    return when {
        dark && high -> Palettes.DarkHighContrast
        dark -> Palettes.Dark
        high -> Palettes.LightHighContrast
        else -> Palettes.Light
    }
}

/** WCAG 2 contrast ratio between two opaque ARGB colours, from 1 (same) to 21 (black on white). */
fun contrast(a: Long, b: Long): Double {
    val (lighter, darker) = listOf(luminance(a), luminance(b)).sortedDescending()
    return (lighter + 0.05) / (darker + 0.05)
}

private fun luminance(argb: Long): Double {
    fun channel(shift: Int): Double {
        val c = ((argb shr shift) and 0xFF) / 255.0
        return if (c <= 0.03928) c / 12.92 else ((c + 0.055) / 1.055).pow(2.4)
    }
    return 0.2126 * channel(16) + 0.7152 * channel(8) + 0.0722 * channel(0)
}
```

```kotlin
import com.jensen.draculanightbynight.content.Story
import com.jensen.draculanightbynight.user.UserState
import java.time.Duration
import java.time.Instant
import java.time.ZoneId

/**
 * When the app must wake next to notify: the next arrival or the new-season prompt, whichever comes first.
 * Null when the reader turned notifications off, Android blocks them, or nothing is left to announce.
 */
fun nextWake(story: Story, user: UserState, now: Instant, zone: ZoneId, notificationsAllowed: Boolean): Instant? {
    if (!user.notify || !notificationsAllowed) return null
    val settings = user.settings ?: return null
    val arrival = Arrivals.nextAfter(story, user, settings, now, zone)
    val prompt = SeasonPrompt.notifyAt(user, zone)?.takeIf { at -> user.lastNotifiedAt?.let { at.toEpochMilli() > it } ?: true }
    return listOfNotNull(arrival, prompt).minOrNull()
}

/** Within this lead time the alarm is aimed straight at the wake; Android's delay is then at most ~1.5 minutes. */
private val AIM_DIRECTLY: Duration = Duration.ofMinutes(2)

/**
 * Where to set the alarm for [wake]. Android may deliver an inexact alarm up to 75 % of its lead time late (at
 * most an hour), so a far wake is approached halfway: the alarm fires before the wake, the app aims again, and
 * only the last couple of minutes are aimed at directly. About ten short wakes a day.
 */
fun alarmFor(wake: Instant, now: Instant): Instant {
    val lead = Duration.between(now, wake)
    return if (lead <= AIM_DIRECTLY) wake else now.plus(lead.dividedBy(2))
}

/** True when the new-season prompt is due at [now] and has not been announced since it fell due. */
fun seasonPromptToNotify(user: UserState, now: Instant, zone: ZoneId): Boolean {
    val at = SeasonPrompt.notifyAt(user, zone) ?: return false
    return !at.isAfter(now) && (user.lastNotifiedAt?.let { at.toEpochMilli() > it } ?: true)
}
```

```kotlin
 * (`lastNotifiedAt`; without one nothing old is announced) and the season prompt. Pure, so the receiver
 * that runs it on the device only has to post the result.
```

```kotlin
        ) {
            return false

        val channel = manager.getNotificationChannelCompat(CHANNEL_NEW_ENTRIES)
        return manager.areNotificationsEnabled() && channel?.importance != NotificationManagerCompat.IMPORTANCE_NONE

        } catch (_: SecurityException) {
            // Permission revoked between the check and the post: nothing to show.
        }
    }
```

```kotlin
package com.jensen.draculanightbynight.notify

import android.app.AlarmManager
import android.app.PendingIntent
import android.content.BroadcastReceiver
import android.content.Context
import android.content.Intent
import android.os.SystemClock
import com.jensen.draculanightbynight.DraculaApp
import com.jensen.draculanightbynight.content.StoryRepository
import com.jensen.draculanightbynight.domain.TimeSource
import com.jensen.draculanightbynight.domain.alarmFor
import com.jensen.draculanightbynight.domain.nextWake
import com.jensen.draculanightbynight.user.UserRepository
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.launch
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import java.time.Duration
import java.time.Instant

/**
 * Keeps one inexact alarm (allowed in Doze, no exact-alarm permission) set for the next moment there is
 * something to announce, and posts the notifications when it fires.
 */
class Notifier(
    private val context: Context,
    private val stories: StoryRepository,
    private val users: UserRepository,
    private val time: TimeSource,
) {
    private val lock = Mutex()

    /** Sets the alarm for the next wake, or cancels it. A reader without a notification baseline gets one now. */
    suspend fun reschedule() = lock.withLock { rescheduleLocked() }

    /** The alarm fired: post what arrived since the baseline, move the baseline to now, set the next alarm. */
    suspend fun onAlarm() = lock.withLock {
        val now = time.now()
        Notifications.post(context, planNotifications(stories.story(), users.state.first(), now.toInstant(), now.zone))
        users.markNotified(now.toInstant().toEpochMilli())
        rescheduleLocked()
    }

    private suspend fun rescheduleLocked() {
        if (users.state.first().lastNotifiedAt == null) users.markNotified(time.millis())
        val now = time.now()
        val wake = nextWake(stories.story(), users.state.first(), now.toInstant(), now.zone, Notifications.allowed(context))
        setAlarm(wake?.let { alarmFor(it, now.toInstant()) }, now.toInstant())
    }

    /**
     * Sets the alarm to fire after the time between [now] and [at] on the app's clock. Counting down (elapsed
     * realtime) rather than naming a wall-clock time keeps the alarm right when a debug build travels in time,
     * and when the device clock is changed it is reset anyway (SystemTimeReceiver).
     */
    private fun setAlarm(at: Instant?, now: Instant) {
        val alarms = context.getSystemService(AlarmManager::class.java) ?: return
        val intent = PendingIntent.getBroadcast(
            context, 0, Intent(context, UnlockReceiver::class.java), PendingIntent.FLAG_IMMUTABLE or PendingIntent.FLAG_UPDATE_CURRENT,
        )
        if (at == null) {
            alarms.cancel(intent)
        } else {
            val lead = Duration.between(now, at).toMillis().coerceAtLeast(0)
            alarms.setAndAllowWhileIdle(AlarmManager.ELAPSED_REALTIME_WAKEUP, SystemClock.elapsedRealtime() + lead, intent)
        }
    }
}

/** The alarm: posts the notifications in the background (goAsync keeps the process alive meanwhile). */
class UnlockReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        val app = (context.applicationContext as DraculaApp).container
        val pending = goAsync()
        app.scope.launch {
            try {
                app.notifier.onAlarm()
            } finally {
                pending.finish()
            }
        }
    }
}

/**
 * Reboot, clock or zone change, app update, notifications blocked or unblocked: the next wake may have moved,
 * and an open timeline should look again at once.
 */
class SystemTimeReceiver : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        if (intent.action !in ACTIONS) return
        val app = (context.applicationContext as DraculaApp).container
        app.time.timeChanged()
        val pending = goAsync()
        app.scope.launch {
            try {
                app.notifier.reschedule()
            } finally {
                pending.finish()
            }
        }
    }

    private companion object {
        val ACTIONS = setOf(
            Intent.ACTION_BOOT_COMPLETED,
            Intent.ACTION_TIME_CHANGED,
            Intent.ACTION_TIMEZONE_CHANGED,
            Intent.ACTION_MY_PACKAGE_REPLACED,
            // NotificationManager's block-state actions (Android 9+); Android 8 never sends them.
            "android.app.action.APP_BLOCK_STATE_CHANGED",
            "android.app.action.NOTIFICATION_CHANNEL_BLOCK_STATE_CHANGED",
        )
    }
}
```

```kotlin
@OptIn(FlowPreview::class)
@Composable
private fun Body(reader: ReaderState, viewModel: ReaderViewModel, modifier: Modifier) {
    val (startItem, startOffset) = listPosition(reader.startBlock, reader.startOffset)
    val listState = rememberLazyListState(startItem, startOffset)
    fun save() {
        val (block, offset) = savedPosition(listState.firstVisibleItemIndex, listState.firstVisibleItemScrollOffset)
        viewModel.savePosition(block, offset)
    }
    // Save while reading (debounced), when the app goes to the background, and once more on leaving,
    // so a killed app still resumes where the reader was.
    LaunchedEffect(reader.entry.id) {
        snapshotFlow { listState.firstVisibleItemIndex to listState.firstVisibleItemScrollOffset }
            .debounce(SAVE_DEBOUNCE_MILLIS)
            .collect { save() }
    }
    LifecycleEventEffect(Lifecycle.Event.ON_PAUSE) { save() }
    DisposableEffect(reader.entry.id) {
        onDispose { save() }
    }
    LazyColumn(modifier.fillMaxSize().padding(horizontal = 20.dp), state = listState) {
        item { Header(reader) }
        itemsIndexed(reader.entry.body) { _, block -> BlockText(block) }
    }
}

private fun annotated(block: Block): AnnotatedString = buildAnnotatedString {
    for (span in block.spans) {
        if (span.italic) withStyle(SpanStyle(fontStyle = FontStyle.Italic)) { append(span.text) } else append(span.text)

@Composable
private fun BlockText(block: Block) {
    // The story text uses the reader's font and size; headers keep the theme's.
    val reading = LocalReadingStyle.current
    val body = reading.applyTo(MaterialTheme.typography.bodyLarge)
    when (block.role) {
        BlockRole.NOTE -> Text(annotated(block), Modifier.fillMaxWidth().padding(bottom = 12.dp), style = reading.applyTo(MaterialTheme.typography.bodyMedium),

        BlockRole.VERSE -> Text(annotated(block), Modifier.fillMaxWidth().padding(start = 24.dp, bottom = 12.dp), style = body, fontStyle = FontStyle.Italic)
        BlockRole.SALUTATION, BlockRole.PARA -> Text(annotated(block), Modifier.fillMaxWidth().padding(bottom = 12.dp), style = body)
```

```kotlin
package com.jensen.draculanightbynight.timeline

import com.jensen.draculanightbynight.content.Dates
import com.jensen.draculanightbynight.content.DocumentType
import com.jensen.draculanightbynight.content.Story
import com.jensen.draculanightbynight.domain.Arrivals
import com.jensen.draculanightbynight.domain.ReadingSettings
import com.jensen.draculanightbynight.domain.isReadable
import com.jensen.draculanightbynight.user.UserState
import java.time.Instant
import java.time.LocalDate
import java.time.ZoneId
import java.time.ZonedDateTime

data class TimelineRow(
    val id: String,
    val authorName: String,
    val type: DocumentType,
    val timeLabel: String,
    val timeEstimated: Boolean,
    val place: String?,
    val preview: String,
    val unread: Boolean,
    val bookmarked: Boolean,
)

data class TimelineDay(val date: LocalDate, val rows: List<TimelineRow>)

/** The next entry to arrive: who writes, what kind of document, and when it really arrives (no text). */
data class NextTeaser(val authorName: String, val type: DocumentType, val unlocksAt: ZonedDateTime)

data class TimelineState(
    val days: List<TimelineDay>,
    val next: NextTeaser?,
    val firstUnreadId: String?,
    val unlockedCount: Int,
    val total: Int,
)

/** What the timeline shows at [now]: readable entries grouped by in-story day, plus the next one to unlock. */
fun buildTimeline(story: Story, user: UserState, settings: ReadingSettings, now: Instant, zone: ZoneId): TimelineState {
    val (unlocked, locked) = story.entries.partition { isReadable(it, settings, user, now, zone) }
    val rows = unlocked.map { e ->
        val progress = user.progressOf(e.id)
        e.date to TimelineRow(
            id = e.id,
            authorName = story.nameOf(e.author) ?: e.author,
            type = e.type,
            timeLabel = e.time.format(Dates.TIME),
            timeEstimated = e.timeEstimated,
            place = e.place,
            preview = e.preview,
            unread = progress.readAtMillis == null,
            bookmarked = progress.bookmarked,
        )
    }
    val days = rows.groupBy({ it.first }, { it.second }).map { (date, dayRows) -> TimelineDay(date, dayRows) }
    val next = locked
        .mapNotNull { e -> Arrivals.arrivesAt(e, settings, zone)?.let { e to it } }
        .minByOrNull { it.second }
        ?.let { (e, at) -> NextTeaser(story.nameOf(e.author) ?: e.author, e.type, at.atZone(zone)) }
    return TimelineState(
        days = days,
        next = next,
        firstUnreadId = rows.firstOrNull { it.second.unread }?.second?.id,
        unlockedCount = unlocked.size,
        total = story.entries.size,
    )
```
```kotlin
}

@Composable
private fun Timeline(state: TimelineState, onOpen: (String) -> Unit, modifier: Modifier = Modifier) {
    val listState = rememberLazyListState()
    // Item index of each row: one header item per day, then its rows.
    val firstUnreadIndex = remember(state.firstUnreadId, state.days) {
        var index = 0
        var found = -1
        for (day in state.days) {
            index++
            for (row in day.rows) {
                if (row.id == state.firstUnreadId) found = index
                index++
            }
        }
        found
    }
    var scrolled by rememberSaveable { mutableStateOf(false) }
    LaunchedEffect(firstUnreadIndex) {
        if (!scrolled && firstUnreadIndex > 0) listState.scrollToItem((firstUnreadIndex - 1).coerceAtLeast(0))
        scrolled = true
    }

    LazyColumn(modifier.fillMaxSize(), state = listState) {
        if (state.days.isEmpty()) {
            item { Text("The story has not begun yet.", Modifier.padding(16.dp), style = MaterialTheme.typography.bodyLarge) }
        }
        for (day in state.days) {
            item(key = "day-${day.date}") {
```

```kotlin
private fun AppNavigation(app: AppContainer, openRequests: MutableStateFlow<String?>, startRoute: String) {
    val nav = rememberNavController()
    // The first screen is chosen once; later state changes (Begin) navigate instead.
    val start = rememberSaveable { startRoute }
    // A tapped notification for one entry opens it over the timeline.
    val request by openRequests.collectAsStateWithLifecycle()
    LaunchedEffect(request) {
        request?.let { id ->
            nav.navigate("reader/$id") { popUpTo("timeline") }
            openRequests.value = null
        }

        composable("welcome") {
            WelcomeScreen(viewModel { WelcomeViewModel(app) }, onBegun = { nav.navigate("timeline") { popUpTo("welcome") { inclusive = true } } })

            TimelineScreen(
                viewModel { TimelineViewModel(app) },
```

```kotlin
/**
 * Asks for Android 13+'s notification permission when the reader turns notifications on, and reports whether it
 * was granted. Earlier Android versions need no permission. Already granted: answers at once, without a dialog.
 */
@Composable
fun rememberNotificationPermissionRequest(onResult: (granted: Boolean) -> Unit): () -> Unit {
    val launcher = rememberLauncherForActivityResult(ActivityResultContracts.RequestPermission(), onResult)
    return {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) launcher.launch(Manifest.permission.POST_NOTIFICATIONS) else onResult(true)
    }
}
```

```kotlin
import androidx.datastore.core.DataStore

/**
 * Reads and writes the reader's saved state. Every change to the schedule (mode, start date, skip ahead,
 * turning notifications on, Start over) moves the notification baseline to now: entries that arrive because
 * of something the reader did are never announced afterwards.
 */
class UserRepository(private val store: DataStore<UserState>, private val time: TimeSource) {
    val state: Flow<UserState> = store.data

    /** Repair: an onboarded reader whose saved mode cannot be read (say, a broken start date) restarts Same tempo from today. */
    suspend fun ensureMode() {
        store.updateData { s -> if (s.readingMode == null) s.withMode(ReadingMode.SameTempo(time.today())) else s }
    }

    /** Begin on the Welcome screen. */
    suspend fun completeOnboarding(mode: ReadingMode, notify: Boolean) {
        store.updateData { it.withMode(mode).copy(onboarded = true, notify = notify, lastNotifiedAt = time.millis()) }
    }

    suspend fun setMode(mode: ReadingMode) {
        store.updateData { it.withMode(mode).copy(lastNotifiedAt = time.millis()) }
    }

    suspend fun setTempoStart(date: LocalDate) {
        store.updateData { it.withMode(ReadingMode.SameTempo(date)).copy(lastNotifiedAt = time.millis()) }
    }

    /** Skip ahead (Read it now, Skip to a day) or, with 0, Back to real time. */
    suspend fun setSkipAhead(minutes: Long) {
        store.updateData { it.copy(skipAheadMinutes = minutes, lastNotifiedAt = time.millis()) }
    }

    suspend fun setNotify(on: Boolean) {
        store.updateData { s -> if (on) s.copy(notify = true, lastNotifiedAt = time.millis()) else s.copy(notify = false) }
    }

    /** After a notification run: entries up to [atMillis] have been announced. */
    suspend fun markNotified(atMillis: Long) {
        store.updateData { it.copy(lastNotifiedAt = atMillis) }
    }

    /** Records the first time an entry was opened; reopening keeps the original time. */
    suspend fun markRead(id: String) {
        store.updateData { s -> s.updateProgress(id) { p -> if (p.readAtMillis != null) p else p.copy(readAtMillis = time.millis()) } }
    }

    suspend fun savePosition(id: String, blockIndex: Int, blockOffset: Int) {
        store.updateData { s -> s.updateProgress(id) { it.copy(blockIndex = blockIndex, blockOffset = blockOffset) } }
    }

    suspend fun toggleBookmark(id: String) {
        store.updateData { s -> s.updateProgress(id) { it.copy(bookmarked = !it.bookmarked) } }
    }

    /** Start over: see [startedOver]. [tempoStart] is the Same tempo restart date (ignored in other modes). */
    suspend fun startOver(removeBookmarks: Boolean, tempoStart: LocalDate) {
        store.updateData { it.startedOver(removeBookmarks, time.today(), tempoStart, time.millis()) }
    }

    /** Records that this year's new-season prompt was answered (Start over or Not now). */
    suspend fun answerSeasonPrompt() {
        store.updateData { it.copy(seasonPromptYear = time.today().year) }
    }

    suspend fun setTextSize(size: TextSize) {
        store.updateData { it.copy(textSize = size) }
    }

    suspend fun setReadingFont(font: ReadingFont) {
        store.updateData { it.copy(readingFont = font) }
    }

    suspend fun setTheme(theme: ThemeChoice) {
        store.updateData { it.copy(theme = theme) }
    }

    /** The reader's own choice; from now on Android's contrast setting no longer decides. */
    suspend fun setHighContrast(on: Boolean) {
        store.updateData { it.copy(highContrast = on) }
    }
}
```

```kotlin
import com.jensen.draculanightbynight.content.Story

import com.jensen.draculanightbynight.domain.firstEntryIsClose
import java.time.LocalDate
import java.time.LocalTime

/**
 * What the Welcome screen says about the modes today: the Calendar season (and whether it has to wait for
 * 3 May), and whether Same tempo should offer to start tomorrow because the first timed entry is close.
 */
data class WelcomeState(
    val today: LocalDate,
    val seasonYear: Int,
    val calendarWaits: Boolean,
    val firstEntryClose: Boolean,
    val firstEntryAuthor: String?,
    val firstEntryTime: LocalTime?,
)

fun buildWelcome(story: Story, now: ZonedDateTime): WelcomeState {
    val today = now.toLocalDate()
    val seasonYear = UnlockSchedule.seasonYearFor(today)
    val seasonStart = UnlockSchedule.STORY_START.withYear(seasonYear)
    val first = story.entries.firstOrNull { it.time != LocalTime.MIDNIGHT }
    return WelcomeState(
        today = today,
        seasonYear = seasonYear,
        calendarWaits = today.isBefore(seasonStart),
        firstEntryClose = firstEntryIsClose(story, today, now.toInstant(), now.zone),
        firstEntryAuthor = first?.let { story.nameOf(it.author) },
        firstEntryTime = first?.time,
    )
}
```

```kotlin
package com.jensen.draculanightbynight.timeline

import java.time.Duration

/** "2 days, 3 hours", "1 hour, 5 minutes", "45 minutes": how far ahead of real time the reader is. */
fun aheadLabel(ahead: Duration): String {
    fun unit(n: Long, word: String) = "$n $word" + if (n == 1L) "" else "s"
    val days = ahead.toDays()
    val hours = ahead.toHours() % 24
    val minutes = ahead.toMinutes() % 60
    val parts = when {
        days > 0 -> listOf(unit(days, "day")) + if (hours > 0) listOf(unit(hours, "hour")) else emptyList()
        hours > 0 -> listOf(unit(hours, "hour")) + if (minutes > 0) listOf(unit(minutes, "minute")) else emptyList()
        else -> listOf(unit(minutes, "minute"))
    }
    return parts.joinToString(", ")
}
```

```kotlin
data class TimelineRow(
    val id: String,
    val authorName: String,
    val type: DocumentType,
    val timeLabel: String,
    val timeEstimated: Boolean,
    val place: String?,
    val preview: String,
    val unread: Boolean,
    val bookmarked: Boolean,
)

data class TimelineDay(val date: LocalDate, val rows: List<TimelineRow>)

/** The next entry to arrive: who writes, what kind of document, and when it really arrives (no text). */
data class NextTeaser(val authorName: String, val type: DocumentType, val unlocksAt: ZonedDateTime)

data class TimelineState(
    val days: List<TimelineDay>,
    val next: NextTeaser?,
    val firstUnreadId: String?,
    val unlockedCount: Int,
    val total: Int,
    /** How far ahead of real time the reader is (zero in real time). */
    val skipAhead: Duration = Duration.ZERO,
    /** Nothing is left to arrive: the end card replaces the Next card. */
    val finished: Boolean = false,
    /** The new-season card shows at the top. */
    val seasonPromptDue: Boolean = false,
)

/** What the timeline shows at [now]: readable entries grouped by in-story day, plus the next one to unlock. */
fun buildTimeline(story: Story, user: UserState, settings: ReadingSettings, now: Instant, zone: ZoneId): TimelineState {
    val (unlocked, locked) = story.entries.partition { isReadable(it, settings, user, now, zone) }
    val rows = unlocked.map { e ->
        val progress = user.progressOf(e.id)
        e.date to TimelineRow(
            id = e.id,
            authorName = story.nameOf(e.author) ?: e.author,
            type = e.type,
            timeLabel = e.time.format(Dates.TIME),
            timeEstimated = e.timeEstimated,
            place = e.place,
            preview = e.preview,
            unread = progress.readAtMillis == null,
            bookmarked = progress.bookmarked,
        )
    }
    val days = rows.groupBy({ it.first }, { it.second }).map { (date, dayRows) -> TimelineDay(date, dayRows) }
    val next = locked
        .mapNotNull { e -> Arrivals.arrivesAt(e, settings, zone)?.let { e to it } }
        .minByOrNull { it.second }
        ?.let { (e, at) -> NextTeaser(story.nameOf(e.author) ?: e.author, e.type, at.atZone(zone)) }
    return TimelineState(
        days = days,
        next = next,
        firstUnreadId = rows.firstOrNull { it.second.unread }?.second?.id,
        unlockedCount = unlocked.size,
        total = story.entries.size,
        skipAhead = settings.skipAhead,
        finished = next == null,
        seasonPromptDue = SeasonPrompt.isDue(user, now.atZone(zone).toLocalDate()),
    )
}
```

```kotlin
@Composable
private fun Timeline(
    state: TimelineState,
    canSkip: Boolean,
    onOpen: (String) -> Unit,
    onReadItNow: () -> Unit,
    onBackToRealTime: () -> Unit,
    onStartOver: () -> Unit,
    onNotNow: () -> Unit,
    modifier: Modifier = Modifier,
) {
    val listState = rememberLazyListState()
    // Item index of each row: one header item per day, then its rows.
    val firstUnreadIndex = remember(state.firstUnreadId, state.days) {
        var index = 0
        var found = -1
        for (day in state.days) {
            index++
            for (row in day.rows) {
                if (row.id == state.firstUnreadId) found = index
                index++
            }
        }
        found
    }
    var scrolled by rememberSaveable { mutableStateOf(false) }
    LaunchedEffect(firstUnreadIndex) {
        if (!scrolled && firstUnreadIndex > 0) listState.scrollToItem((firstUnreadIndex - 1).coerceAtLeast(0))
        scrolled = true
    }

    // The season card and the ahead banner stay pinned above the list: the list opens scrolled to the first
    // unread entry, which would otherwise hide them exactly when they matter.
    Column(modifier.fillMaxSize()) {
        if (state.seasonPromptDue) SeasonCard(onStartOver, onNotNow)
        if (!state.skipAhead.isZero) AheadBanner(state, onBackToRealTime)
        TimelineList(state, listState, canSkip, onOpen, onReadItNow, onStartOver)
    }
```

```kotlin
sealed interface TimelineUi {
    data object Loading : TimelineUi
    data class Ready(val timeline: TimelineState, val mode: ReadingMode, val today: LocalDate, val bookmarks: Int) : TimelineUi
}

class TimelineViewModel(private val app: AppContainer) : ViewModel() {
    val state: StateFlow<TimelineUi> = combine(flow { emit(app.stories.story()) }, app.users.state, app.time.ticks()) { story, user, now ->
        val settings = user.settings ?: return@combine TimelineUi.Loading
        TimelineUi.Ready(
            buildTimeline(story, user, settings, now.toInstant(), now.zone),
            settings.mode,
            now.toLocalDate(),
            bookmarks = user.progress.values.count { it.bookmarked },
        )
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(STOP_TIMEOUT_MILLIS), TimelineUi.Loading)

    init {
        viewModelScope.launch { app.users.ensureMode() }
    }

    /** Re-picking the current kind of mode keeps it; only a different kind is stored. */
    fun setMode(picked: ReadingMode) {
        viewModelScope.launch {
            val current = app.users.state.first().readingMode
            val mode = pickMode(current, picked)
            if (mode != current) app.users.setMode(mode)
        }
    }

    /** "Read it now": skip ahead just far enough for the next entry to arrive. */
    fun readItNow() {
        viewModelScope.launch {
            val user = app.users.state.first()
            val settings = user.settings ?: return@launch
            val now = app.time.now()
            app.users.setSkipAhead(SkipAhead.toNext(app.stories.story(), user, settings, now.toInstant(), now.zone))
        }
    }

    fun backToRealTime() {
        viewModelScope.launch { app.users.setSkipAhead(0) }
    }

    /** Start over from the end card or the new-season card; either way this year's season prompt is answered. */
    fun startOver(removeBookmarks: Boolean, tempoStart: LocalDate) {
        viewModelScope.launch {
            app.users.startOver(removeBookmarks, tempoStart)
            app.users.answerSeasonPrompt()
        }
    }

    /** "Not now" on the new-season card. */
    fun dismissSeasonPrompt() {
        viewModelScope.launch { app.users.answerSeasonPrompt() }
    }

    private companion object {
        const val STOP_TIMEOUT_MILLIS = 5_000L
    }
}
```

```kotlin
    val nav = rememberNavController()

    val start = rememberSaveable { startRoute }

    val request by openRequests.collectAsStateWithLifecycle()

        request?.let { id ->
            nav.navigate("reader/$id") { popUpTo("timeline") }
            openRequests.value = null
        }
```

```kotlin
/** Everything the Settings screen shows. */
data class SettingsState(
    val mode: ReadingMode,
    val modeLabel: String,
    val today: LocalDate,
    /** Same tempo's day one, or null in the other modes. */
    val tempoStart: LocalDate?,
    val ahead: Duration,
    /** The story days "Skip to a day" offers: every date that has an entry, in story order. */
    val storyDays: List<LocalDate>,
    /** Same tempo started today with the first timed entry under an hour away (or past): offer tomorrow. */
    val offerStartTomorrow: Boolean,
    val firstEntryAuthor: String?,
    val firstEntryTime: LocalTime?,
    val bookmarks: Int,
    val notify: Boolean,
    val textSize: TextSize,
    val readingFont: ReadingFont,
    val theme: ThemeChoice,
    val highContrast: Boolean?,
)

fun modeLabel(mode: ReadingMode): String = when (mode) {
    is ReadingMode.Calendar -> "On the actual days (${mode.seasonYear})"
    is ReadingMode.SameTempo -> "In the same tempo"
    ReadingMode.Free -> "Read freely"
}

fun buildSettings(story: Story, user: UserState, now: ZonedDateTime): SettingsState {
    val mode = user.readingMode ?: ReadingMode.Free
    val today = now.toLocalDate()
    val tempoStart = (mode as? ReadingMode.SameTempo)?.startDate
    val first = story.entries.firstOrNull { it.time != LocalTime.MIDNIGHT }
    return SettingsState(
        mode = mode,
        modeLabel = modeLabel(mode),
        today = today,
        tempoStart = tempoStart,
        ahead = Duration.ofMinutes(user.skipAheadMinutes),
        storyDays = story.entries.map { it.date }.distinct(),
        offerStartTomorrow = tempoStart == today && firstEntryIsClose(story, today, now.toInstant(), now.zone),
        firstEntryAuthor = first?.let { story.nameOf(it.author) },
        firstEntryTime = first?.time,
        bookmarks = user.progress.values.count { it.bookmarked },
        notify = user.notify,
        textSize = user.textSize,
        readingFont = user.readingFont,
        theme = user.theme,
        highContrast = user.highContrast,
    )
}
```

```kotlin
@Composable
private fun Timeline(
    state: TimelineState,
    canSkip: Boolean,
    onOpen: (String) -> Unit,
    onReadItNow: () -> Unit,
    onBackToRealTime: () -> Unit,
    onStartOver: () -> Unit,
    onNotNow: () -> Unit,
    modifier: Modifier = Modifier,
) {
    val listState = rememberLazyListState()
    // Item index of each row: one header item per day, then its rows.
    val firstUnreadIndex = remember(state.firstUnreadId, state.days) {
        var index = 0
        var found = -1
        for (day in state.days) {
            index++
            for (row in day.rows) {
                if (row.id == state.firstUnreadId) found = index
                index++
            }
        }
        found
    }
    var scrolled by rememberSaveable { mutableStateOf(false) }
    LaunchedEffect(firstUnreadIndex) {
        if (!scrolled && firstUnreadIndex > 0) listState.scrollToItem((firstUnreadIndex - 1).coerceAtLeast(0))
        scrolled = true
    }

    // The season card and the ahead banner stay pinned above the list: the list opens scrolled to the first
    // unread entry, which would otherwise hide them exactly when they matter.
    Column(modifier.fillMaxSize()) {
        if (state.seasonPromptDue) SeasonCard(onStartOver, onNotNow)
        if (!state.skipAhead.isZero) AheadBanner(state, onBackToRealTime)
        TimelineList(state, listState, canSkip, onOpen, onReadItNow, onStartOver)
    }
}
```
