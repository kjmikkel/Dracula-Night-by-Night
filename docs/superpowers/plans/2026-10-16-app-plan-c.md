# App Plan C: Look, About, Release-ready — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app gets its restrained gothic look (light), candlelight (dark), document touches in the reader, a Tonight card, a pen-nib icon, an About page and privacy policy, a release build that is signed when a key exists and shrunk with R8, and the plan A/B leftovers fixed.

**Architecture:** Logic stays pure Kotlin tested on the JVM: palettes and contrast (`ui/Palette.kt`), the Tonight card (`timeline/Tonight.kt`), the reschedule key (`notify/ScheduleKey.kt`) and the repository/bookmark leftovers. Compose screens, icon resources, Gradle release config and CI are verified on the emulator and in CI.

**Tech Stack:** as plan B; no new libraries. New bundled fonts: IM Fell English, IM Fell English SC (SIL OFL 1.1), Special Elite (Apache-2.0).

**Spec:** `docs/superpowers/specs/2026-10-16-app-plan-c-design.md` (C1–C10 and the leftover list 1–13).

**Prerequisite:** plans A and B merged (main at `f360e19` or later). Signatures and tests are fixed here; bodies are the implementer's.

## Global Constraints

- Package `com.jensen.draculanightbynight`; minSdk 26; compileSdk/targetSdk 37; no network permission; no proprietary dependencies.
- Contrast: every text/background pair ≥ 4.5:1 in Light and Dark, ≥ 7:1 in both high-contrast palettes (`PaletteTest`), including selection colours.
- The display face is for headings only; story text always uses the reader's chosen reading font.
- Ornaments are decorative: `contentDescription = null` / `clearAndSetSemantics {}`.
- Every date and weekday in English via `content/Dates.kt`; times from the app clock (`ShiftableClock` / `TimeSource`).
- No keystore, password or `keystore.properties` in git.
- Fonts bundled unmodified with their licence texts in `assets/licenses/`.
- Gradle from `app/` as `JAVA_HOME="C:/Program Files/Android/Android Studio/jbr" ./gradlew …`; commits end `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; PR bodies end `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.

## Rulings made while writing this plan (flagged for the maintainer)

1. **The reschedule key leaves out `lastNotifiedAt`.** Every writer that changes only the baseline is the notifier itself (`markNotified`), which reschedules right after; every other baseline move comes with a schedule change that is in the key.
2. **No legacy PNG launcher icons:** minSdk 26 means every supported launcher takes the adaptive icon.
3. **The store icon PNG is rendered from an SVG copy of the same drawing** (`docs/icon/icon.svg` → `docs/icon/icon-512.png`) with any SVG renderer available locally; it is not part of the APK.
4. **Pinned cards give way by joining the list** when the window is short (`LocalConfiguration.current.screenHeightDp < 480`): then the season, ahead, filtered and Tonight cards are the list's first items instead of pinned.
5. **Bookmarks Undo is per snackbar:** each snackbar's Undo restores the row it names; dismissing a snackbar (by a newer one) gives up its Undo, as before, but the text now says which entry was removed.
